# Roles

This repo includes these roles:

- `common`
- `jenkins`
- `sonarqube`
- `harbor`
- `vault`
- `minio`

Use the main project config in `config.yaml` for normal usage.

If you want to see role variables, check:

- `roles/VARIABLES.md`

Each role README explains only:

- what that role installs
- the main settings
- how to turn it on in this repo
